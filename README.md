# Sujith PS — VFX Portfolio

## Add your content
1. `assets/portrait.jpg` — your photo (dark/plain bg, facing left works best)
2. `assets/showreel-poster.jpg` — showreel thumbnail (16:9)
3. `index.html` — set `data-video` to your YouTube/Vimeo **embed** link
4. `projects.html` — edit/copy project cards; add `assets/project1.jpg` etc.
5. `contact.html` + footer — replace email, LinkedIn, Instagram, Vimeo links

## Host on GitHub Pages
1. New repo → upload all files (index.html at root)
2. Settings → Pages → Source: `main` branch, `/ (root)` → Save
3. Live at `https://USERNAME.github.io/REPO/`
   (name the repo `USERNAME.github.io` for a clean URL)
